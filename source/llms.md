# Penida resources for language models

The Penida website is available as complete HTML, with Markdown versions of its main pages. These resources help readers and tools retrieve the same public information without running the site’s interface scripts.

Updated: September 23, 2026.

## Start here

- [Official Penida reference](/ai) — studio, current product links, contact and portfolio updates.
- [llms.txt](/llms.txt) — a short index of the main sources.
- [llms-full.txt](/llms-full.txt) — a combined Markdown reference including the studio summary, articles and website policies.
- [Sitemap](/sitemap.xml) — the site’s canonical HTML pages.

The `llms.txt` format is a [community proposal](https://llmstxt.org/). Providing these resources does not guarantee that an AI service will discover, index or cite the website.

## Scope and freshness

The reference pages and articles show their revision date. Product pricing, usage figures and app ratings are not maintained as a live data source here; consult each product’s current official website or Shopify listing for those details.

The Markdown versions are generated with the website so that edits stay consistent across formats. The resources do not change access permissions or bypass the website’s crawler rules. Questions or corrections can be sent to [penidastudio@gmail.com](mailto:penidastudio@gmail.com).
